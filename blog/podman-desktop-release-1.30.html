Podman Desktop 1.30 Release

October 14, 2026 · 23 min read
Simon Rey
Senior Software Engineer

Podman Desktop 1.30 Release

Podman Desktop 1.30 is now available. Click here to download it!

This release includes new features, bug fixes, and continues the Svelte 5 migration:

  • Bulk container stop: Select multiple running containers and stop them in one click.
  • Warning-level preflight checks: Preflight checks on Windows can now warn instead of block.
  • No more console flashes on Windows: Machine autostart no longer pops up a Command Prompt window.
  • Docker contexts as connections: Each Docker context is now surfaced as its own container connection.
  • Extension API additions: Searchable routes in the command palette and display names for configuration properties.

Release details​

Bulk container stop​

You can now select multiple containers from the list and stop them all with a single action.

Warning severity for preflight checks​

Preflight checks during onboarding previously only had two outcomes: pass or fail. The API now supports a warning severity. A check can flag a potential issue with a ⚠️ icon without blocking the setup.

On Windows, a new BIOS virtualization firmware check uses this: if hardware virtualization is not enabled in the BIOS and no hypervisor is present, the check reports a warning instead of a hard failure, so you can still proceed with the Podman installation.

No more console window flashes on Windows​

On Windows, autostarting a Podman machine at launch no longer causes a Command Prompt window to briefly flash on screen (#19318).

Docker contexts as container connections​

If you work with Docker alongside Podman, Podman Desktop now registers a separate container connection for each configured Docker context. Whether you have a local daemon, a remote host, or multiple Docker Desktop contexts, they all appear individually on the dashboard without manual switching.

Extension API improvements​

Two additions for extension authors:

  • Searchable routes in the command palette: Extensions can now pass a searchEntry option to navigation.register() to make their pages discoverable from the command palette (#18550).
  • Configuration display names: Extension manifests can now declare a displayName on configuration properties. When present, the Settings UI shows this label instead of the raw property key (#19186, #19203).

Other improvements​

  • Keyboard shortcut validation utils: New keyboard utilities for validating keyboard shortcuts (#19314).
  • CI telemetry detection: Telemetry is now automatically disabled when a CI environment is detected (#19266).
  • FileInput disabled state and error display: The FileInput component can now be disabled and display validation errors (#19300).
  • Table row onClick API: The Table component now supports an onClick handler on rows (#18893).
  • ButtonRow component: A new ButtonRow UI component standardizes button layout in dialogs and forms (#18724).
  • Button aria-pressed toggle support: Buttons can now expose a pressed prop for accessible toggle behavior (#18591).
  • Themed image support in Icon: The Icon component now supports themed images that adapt to light/dark modes (#18558).
  • Cancel long press on pointer movement: Long press gestures are now properly cancelled when the pointer moves away (#18569).
  • Expandable settings navigation sections: Settings navigation now supports expandable sections with children for better organization (#19125).
  • Navigation item pinning (backend): The backend now supports pinning navigation items to the top of the sidebar (#18464).
  • Network menu context contributions: Extensions can now contribute menu actions to the network context menu (#18601).
  • Declarative env:/file: configuration defaults: Configuration properties now support env: and file: prefixes for dynamic default values (#18797).
  • Infra container detection: Podman Desktop now detects and labels infrastructure containers (#18892).
  • Startup update dialog improvements: The dismiss buttons in the startup update dialog are now grouped under a "Later" dropdown (#19194).
  • Managed configuration for provider updates: A new managed configuration controls whether provider update notifications are shown (#17878).
  • 5M downloads banner on website: A celebratory banner marks the 5 million downloads milestone (#18533).
  • Svelte 5 migration: Over 100 renderer components migrated to Svelte 5 runes by @gastoner and @0xKalasi, covering Preferences, Extensions, Containers, Volumes, Compose, Kubernetes resources, PVCs, and Icons.
  • Replaced got with native fetch in image-registry (#18523).
  • Removed win-ca dependency (#18187).
  • Extracted DockerDaemonMonitor from the Docker extension (#18524).
  • Switched ESLint from parserOptions.project to projectService (#19265).
  • Bundled express instead of externalizing it in Vite (#19239).
  • Used discriminated unions in getMatchingConnectionFromProvider (#14840).
  • Bumped Podman v5 to 5.8.9 and Podman v6 to 6.1.4, addressing CVE-2026-94603 (checkpoint image sandboxing bypass).

Notable bug fixes​

  • Windows console flash: Background process spawning on Windows no longer flashes a console window (#19318).
  • High-contrast navbar focus: The focus outline on selected navbar items is now visible in high-contrast themes (#19323).
  • Rosetta configuration: The Podman extension now always writes an explicit Rosetta value in containers.conf, preventing silent misconfigurations (#19238).
  • Remote Podman connections: Connections that have no Identity field are now registered correctly (#19147).
  • Zstd decompression bombs: Streaming zstd layer decompression now rejects decompression bombs (#19166).
  • Atomic configuration writes: Storage and configuration files now use atomic writes and serialization, preventing corruption on concurrent access (#19071).
  • UTF-8 log streaming: Multi-byte UTF-8 characters split across stream chunks are now preserved correctly in container logs (#17994).
  • WSL error surfacing: WSL errors are now surfaced directly instead of showing misleading notifications (#17936).
  • Accurate memory usage: The dashboard now uses memAvailable for accurate Podman memory usage reporting (#18418).
  • Container command display: The full container command is now shown, not only its first argument (#18561).
  • Typeahead cleanup: The Typeahead input delay timeout is now properly cleared on component destruction (#19223).
  • Slider styling: The preferences slider track now shows a proper two-tone fill gradient (#19158).
  • Network name ordering: Network views now show the network name before the ID (#18917).
  • Lima empty configuration values: Empty Lima configuration values are now treated as unset (#18639).
  • Registry path spaces: Spaces in registry configuration paths are now supported on Podman (#18542).
  • Hyper-V cleanup during migration: Hyper-V VMs are now cleaned up during migration data reset (#18791).
  • Welcome page overlay: The resize handle no longer appears above the welcome overlay (#18998).
  • Long error messages: Long unbreakable error messages now wrap correctly in the UI (#19301).
  • Tooltip after menu close: Tooltips no longer reappear after a menu closes (#18864).
  • Dashboard socket liveness on Linux: The Podman tile on the dashboard now correctly updates socket liveness on Linux (#18580).
  • Toggle Timestamps accessibility: The Toggle Timestamps button in container logs now has proper accessibility attributes (#18627).
  • Sentence case for tab labels: Tab labels now use consistent sentence case (#18885).
  • App navigation resize glitch: The sidebar navigation no longer glitches when resizing (#18593).
  • Task Manager deep-linking: Clicking "see more" on a failed connection lifecycle task now navigates to the actual connection page instead of the generic Resources list (#19345).
  • Experimental feature feedback dialog: The dialog was never shown at startup because it fired before the renderer was ready. It now waits for extensions to finish loading (#18562).
  • Flatpak StartupWMClass mismatch: The StartupWMClass in the Flatpak desktop entry now matches the actual Electron window class, fixing broken task manager icon linking on KDE Plasma/Wayland (#19403).
  • Extension README loading: Extension READMEs are now fetched from the main process instead of the renderer, fixing CSP errors that prevented README display for uninstalled extensions (#19472).
  • JS exception pop-ups on quit: Closing the main window no longer triggers JavaScript exception pop-ups from streams trying to send events to the destroyed window (#19328).
  • Webview file server directory boundary: The webview file server now enforces proper directory boundaries using path.relative, preventing path traversal to sibling extension directories (#19613).

Known issues​

  • WSL v3.0.1 breaks podman run: Windows users who have updated to WSL v3.0.1 may see a crun: controller 'pids' is not available error when running containers. This is an upstream Podman issue. As a workaround, you can either pass --cgroups=disabled to podman run, or add cgroup_manager="cgroupfs" under [engine] in your containers.conf file.
